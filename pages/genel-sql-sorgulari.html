Genel SQL Sorguları Ne İşe Yarar?

Genel SQL sorguları; tablo boyutu analizi, hata kayıtları, performans incelemeleri, veri kalite kontrolleri ve sistem log raporları gibi konularda hızlı görünürlük sağlar. Bu sorgular, ERP bağımsız olarak birçok projede işe yarayan pratik yardımcı araçlardır.

// hazır sorgular

Hazır Genel SQL Örnekleri

Aşağıdaki sorgular sistem analizi, performans takibi ve yardımcı raporlama için kullanılabilir.

En Büyük Tablolar
Genel
SELECT TOP 20 t.NAME AS TABLO_ADI, SUM(p.rows) AS SATIR_SAYISI, CAST(ROUND((SUM(a.total_pages) * 8) / 1024.0, 2) AS DECIMAL(18,2)) AS TOPLAM_MB FROM sys.tables t JOIN sys.indexes i ON t.object_id = i.object_id JOIN sys.partitions p ON i.object_id = p.object_id AND i.index_id = p.index_id JOIN sys.allocation_units a ON p.partition_id = a.container_id WHERE t.is_ms_shipped = 0 GROUP BY t.NAME ORDER BY TOPLAM_MB DESC
Veritabanında en çok alan kaplayan tablolar
Son 7 Günlük Hata Kayıtları
Genel
SELECT LOG_TARIHI, MODUL, HATA_KODU, HATA_MESAJI FROM APP_ERROR_LOG WHERE LOG_TARIHI >= DATEADD(day, -7, GETDATE()) ORDER BY LOG_TARIHI DESC
Son 7 gün içinde oluşan hata kayıtlarını listeler
Yavaş Sorguları Tespit Et
Genel
SELECT TOP 20 SUBSTRING(qt.TEXT, (qs.statement_start_offset/2) + 1, ((CASE qs.statement_end_offset WHEN -1 THEN DATALENGTH(qt.TEXT) ELSE qs.statement_end_offset END - qs.statement_start_offset)/2) + 1 ) AS SORGU_METNI, qs.execution_count AS CALISMA_SAYISI, qs.total_elapsed_time / qs.execution_count AS ORT_SURE_MS FROM sys.dm_exec_query_stats qs CROSS APPLY sys.dm_exec_sql_text(qs.sql_handle) qt ORDER BY ORT_SURE_MS DESC
En yavaş çalışan sorguları listeler
Boş veya Null E-Postalar
Genel
SELECT ID, AD_SOYAD, EMAIL FROM MUSTERILER WHERE EMAIL IS NULL OR LTRIM(RTRIM(EMAIL)) = ''
Eksik e-posta bilgisi olan kayıtları bulur
Günlük Kayıt Artış Özeti
Genel
SELECT CONVERT(date, CREATED_AT) AS TARIH, COUNT(*) AS KAYIT_SAYISI FROM KAYITLAR WHERE CREATED_AT >= DATEADD(day, -30, GETDATE()) GROUP BY CONVERT(date, CREATED_AT) ORDER BY TARIH DESC
Son 30 günlük kayıt artışını gün bazında gösterir
