SQL Formatter Nasıl Kullanılır?

Üç adımda SQL sorgunuzu düzenleyin.

1. SQL yazın veya yapıştırın
Sol alana ham SQL sorgunuzu yapıştırın. Girintisiz, dağınık halde olması sorun değil.
2. Dil seçin ve formatla
SQL Server, MySQL veya PostgreSQL seçip "Formatla" butonuna tıklayın. Sözdizimi otomatik düzenlenir.
3. Kopyalayın veya indirin
Formatlanmış sorguyu kopyalayın ya da .sql dosyası olarak indirin. ERP raporlarınıza yapıştırın.
